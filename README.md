# My Personal Website 🌐

Welcome to the repository for my personal website, hosted live via GitHub Pages. It serves as my digital portfolio, project gallery, and resume.

## 🔗 Live Site
You can visit the live website here: https://vignesh0906.github.io

## 🛠️ Built With
- **HTML5 & CSS3** - Core structure and basic layouts.
- **Jekyll** - Static site generation tool.
- **GitHub Pages** - Hosting and automated deployment pipeline.

## 📁 Repository Structure
- `index.html`: The central landing page layout and entry file.
- `_config.yml`: Global site settings, metadata, and theme variables.
- `assets/`: *(Optional future folder)* For hosting custom CSS styles, logos, and profile images.

## 🚀 Running Locally
If you want to test or make changes to this website on your local machine:
1. Clone this repository down to your computer.
2. Edit the text or project cards inside `index.html`.
3. Open `index.html` directly in any web browser to preview changes before pushing them live to GitHub.
